## Браузерные сценарии

1. Регистрация и отображение пустой базы.
2. Ошибка при неверном ZIP без частичной записи данных.
3. Импорт исходного архива, анализ и совпадение KPI с API.
4. Пагинация, серверная сортировка и фильтрация очереди по роли.
5. Поиск по точному 18-значному GID, карточка узла, настоящие связи и глубина окружения.
6. Открытие кластера и переход к его очереди проверки.
7. Скачивание всех трёх CSV через авторизованный запрос.
8. Повторный анализ с тем же результатом и сохранение сессии после перезагрузки.
9. Понятная ошибка недоступности API и восстановление после повторного запроса.
10. Экранирование текста из базы и отсутствие горизонтального переполнения страницы при ширине 390 px.
11. Недействительный токен, повторный вход и очистка интерфейса при выходе.

Дополнительные API-тесты проверяют отказ без авторизации, неизвестный GID, границу
четвёртого колена, изоляты, точность строковых GID, числовые объяснения, состав CSV,
детерминированность расчёта, ошибки связности и сумм, повторный импорт и откат неуспешного анализа.

## Границы результата

Анализ представляет собой детерминированные эвристики, а не обученную AML-модель.
`role_score` и `priority_score` не являются вероятностями нарушений. Ручное изменение
исходного графа через CRUD требует последующего пересчёта. Локальный запуск использует
один процесс Uvicorn; роли пользователей и изоляция данных по пользователю не реализованы.
